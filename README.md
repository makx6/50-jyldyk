# Чакыруу — Эркинбектин 50 жылдык мааракеси

Сайт-приглашение на юбилей. Статика, без сборки.

**Торжество:** 21 ноября 2026 (ишемби), 17:00
**Место:** ресторан «Altyn Kazyna», Жеңиш проспектиси (пр. Победы), 351, Бишкек

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка и весь текст приглашения |
| `styles.css` | Оформление, орнамент, анимации |
| `script.js` | Музыка, таймер, календарь, появление секций |
| `assets/music.mp3` | Фоновая музыка |
| `assets/map-2gis.jpg` | Скриншот карты 2ГИС (кликабелен, ведёт в 2ГИС) |

## Как поменять текст

Весь текст — прямо в `index.html`. Дата задаётся **в двух местах**, менять надо оба:

- `index.html` → блок `.panel--when` (`21-ноябрь, 2026` и `Ишемби`)
- `script.js` → `TOI` (таймер) и `marked` (кружок в календаре)

## Музыка

Шопен, Ноктюрн соль мажор, соч. 37 № 2 (исп. Olga Gurevich).
Лицензия CC0 1.0 — общественное достояние, можно использовать свободно.
Источник: [archive.org](https://archive.org/details/parso-1c53a71e4ef6f47591ab605d801bc3780b27824a)

Браузеры запрещают автозапуск звука, поэтому музыка включается после нажатия
«Чакырууну ачуу» на заставке. Кнопка в правом нижнем углу выключает её.
